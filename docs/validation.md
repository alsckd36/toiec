명령: `./gradlew --no-daemon --max-workers=2 :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`

- 최종 실행 BUILD SUCCESSFUL.
- JVM 단위 테스트 15개: 통과 15, 실패 0, 오류 0, 건너뜀 0.

- 알려진 다른 뜻·겹치는 뜻·등록한 유사 의미군이 오답 보기에서 제외되는지 확인.
- 정답 위치가 네 위치에 분산되는지 확인.
- 오답 선택 즉시 저장, 재선택 무시, 정답 수 중복 증가 방지 확인.
- 반복 오답 저장의 중복 방지, 일반 학습 정답의 기존 오답 유지 확인.
- 복습 정답 즉시 제거와 복습 오답 유지 확인.
- 실제 임시 파일을 이용하여 저장소 객체를 새로 생성한 뒤 오답이 유지되고 삭제 상태가 유지되는지 확인.
- 다른 단어를 삭제해도 기존 오답이 보존되는지 확인.
- 파일 저장 실패 시 미채점 상태 유지 및 진행 차단 확인.
- 답 선택 전 다음 진행 차단, 전체 세션 완료와 정답 수 집계 확인.
- 보기 부족 또는 잘못된 선택 값은 잘못된 문제·기록을 만드는 대신 오류 처리.

- 원본 엑셀의 추출 전후 및 최종 SHA-256이 동일. Test 자료 미포함 확인.
- APK 패키지 `com.toiec.vocabulary`, versionCode 2, versionName 1.1, 최소 API 26·타깃 API 36, INTERNET 권한 없음.

## 실제 Android 기기에서 확인하지 못한 항목

등록된 AVD 없음. 이 머신에 `/dev/kvm`과 USB 접근 경로가 없습니다.
기기 설치, 실제 화면 동작, 터치·화면 회전, Android 앱 내부 파일의 실제 저장·재실행은 아직 검증하지 못했습니다.
JVM 파일 테스트는 Android 런타임 테스트를 대체하지 않습니다.

휴대폰에서 다음 흐름을 확인하세요:

1. 인터넷을 끄고 실행 → DAY 목록과 항목 수 확인 → DAY 선택 후 학습 시작.
2. 답 선택 → 내 선택·정답 확인 → 다른 답을 눌러도 바뀌지 않는지 확인 → 다음.
3. 일부러 오답 선택 → 홈으로 종료 → 오답노트에서 단어 확인.
4. 앱 종료·재실행 → 해당 오답 유지 확인.
5. 오답 복습에서 다시 오답 → 유지 확인; 다시 복습에서 정답 → 즉시 제거 확인.
6. 앱 종료·재실행 → 제거 상태 유지 확인.
7. 학습 중 화면 회전 → 문제·보기·채점 상태 유지 확인.
